# FUNLANDIA Telegram Bot

Готовая первая версия бота:
- меню FUNLANDIA;
- цены;
- расписание;
- адрес;
- Instagram;
- развлечения;
- заявка на день рождения;
- уведомление администратора (если задан ADMIN_CHAT_ID);
- русский интерфейс и заготовка узбекского раздела.

## Запуск

1. Установить Python 3.11+.
2. Установить зависимости:
   `pip install python-telegram-bot==22.5`
3. Задать переменную `BOT_TOKEN` — токен, который выдал @BotFather.
4. При необходимости задать `ADMIN_CHAT_ID`.
5. Запустить:
   `python bot.py`

Не публикуйте токен BotFather в чате или репозитории.
